# ひらがな・カタカナ学習アプリ 企画書

対象：5歳児（年中〜年長）とその保護者
形態：ブラウザで動くWebアプリ（タブレット＋指／タッチペンでの利用を主に想定）

---

## 1. 調査：科学的に効果があるとされる学習方法

本章では、研究で効果が示されている方法と、それぞれがアプリの設計にどう結びつくかを整理する。
（※出典は代表的な研究名を挙げている。実装前に必要に応じて原典を確認すること。）

### 1-1. 「手で書く」ことが文字の読みを強くする
- **研究内容**：James & Engelhardt (2012) は、就学前の子どもが文字を「手で書いた」場合にだけ、文字を見たときの脳の読字ネットワーク（紡錘状回など）が活性化したと報告している。文字を「タイプした」場合や「なぞった（トレースのみ）」場合は、この効果が弱かった。Longcamp ら (2005) も、3〜5歳児は手書きで覚えた文字の方がキーボードで覚えた文字よりも識別が正確だったと報告している。
- **アプリへの反映**：アプリは「見る・聞く」だけで終わらせず、子どもが指で実際に書く練習を中心に置く。また、アプリは「なぞり」から「自分で書く」へと段階的に支えを減らしていく（1-4参照）。

### 1-2. 書き順の動きを見せる（運動のお手本）
- **研究内容**：文字の書き方を学ぶとき、完成した形だけを見せるよりも、1画ずつ動きとして見せるほうが、形の再現がよくなるという報告がある（運動学習・手書き指導の研究）。書き順は、日本の小学校の書写指導でも基本として扱われる。
- **アプリへの反映**：アプリは書き順アニメーション（1画ずつ、始点に番号と丸を表示）を見せる。また、アプリは子どもが書くときも各画の「はじまりの点」を光らせ、画の順番と方向を判定する。

### 1-3. 文字と音を結びつける・音のまとまり（拍）に気づく
- **研究内容**：天野清 (1970年代〜) の研究では、ことばを「拍（モーラ）」に分ける力（例：「りんご」は「り・ん・ご」の3つ）が育つと、かな文字の読みの習得が進むことが示されている。日本語のかなは1文字が1拍に対応するため、この「音韻意識」が読みの土台になる。
- **アプリへの反映**：アプリは文字を書いたあとに必ず音声で読み上げる。単語の学習では、アプリは単語を拍ごとに区切って1文字ずつ光らせながら読み上げ、「り・ん・ご」で手をたたくようなリズム遊びも入れる。

### 1-4. 支えを少しずつ外していく（スキャフォールディング）
- **研究内容**：ヴィゴツキーの「発達の最近接領域」の考え方や、その後の教育研究では、最初は手厚く支え、できるようになるにつれて支えを減らす方法（フェーディング）が効果的とされる。
- **アプリへの反映**：アプリは1文字ごとに次の4段階を用意する。
  1. **見る**：書き順アニメーションを見る
  2. **なぞる**：濃いお手本の上をなぞる
  3. **うすくなぞる**：うすいお手本と始点だけを手がかりに書く
  4. **ひとりで書く**：お手本なしでマスの中に書く

### 1-5. 思い出す練習（テスト効果）と間隔をあけた復習（分散学習）
- **研究内容**：Roediger & Karpicke (2006) は、読み返すよりも「思い出そうとする」練習のほうが記憶が長く残ること（テスト効果）を示した。Cepeda ら (2006) のメタ分析は、一度にまとめて学ぶより、時間をあけて何度か学ぶほうが記憶が定着すること（分散学習）を示している。
- **アプリへの反映**：アプリは覚えた文字を、翌日・3日後・1週間後などに「おさらいクイズ」として自動で出す。クイズは「音を聞いて文字を選ぶ」「絵を見て最初の文字を選ぶ」などの“思い出す”形式にする。

### 1-6. 複数の感覚を使う（多感覚学習）
- **研究内容**：視覚・聴覚・運動（書く動き）を組み合わせる多感覚学習は、文字学習で広く使われ、効果が報告されている（例：オートン・ギリンガム法の系譜の研究）。
- **アプリへの反映**：アプリは「見る（文字と絵）」「聞く（読み上げ）」「書く（指でなぞる）」を1回の学習の中で必ずセットにする。

### 1-7. 短い時間・すぐのフィードバック・ほめ方
- **研究内容**：
  - 幼児の集中が続く時間は短いため、短い活動をくり返す方がよいとされる。また、世界保健機関（WHO, 2019）や米国小児科学会（AAP）は、2〜5歳の画面を見る時間を1日1時間以内にするよう推奨している。
  - すぐにフィードバックがあると学習が進みやすい（フィードバック研究のメタ分析：Hattie & Timperley 2007 など）。
  - Mueller & Dweck (1998) は、「かしこいね」と能力をほめるより、「がんばったね」「ていねいに書けたね」と取り組みをほめるほうが、子どもが難しい課題に挑戦し続けやすいことを示した。
- **アプリへの反映**：
  - アプリは1回の学習を約5〜10分にし、保護者が1日の時間の上限を設定できるようにする。
  - アプリは1画ごとにすぐ反応を返す（うまく書けたら光る・音が鳴る）。
  - アプリは失敗を「×」で示さず、「もういっかい やってみよう」とやさしく促し、正しい画の動きをもう一度見せる。
  - アプリのほめ言葉は「ていねいに かけたね」「さいごまで がんばったね」など、取り組みをほめる内容にする。

### 1-8. 5歳児の発達の実態
- **調査内容**：国立国語研究所の調査（1967年）や、島村直己・三神廣子 (1994) の調査では、年長児の多くがひらがなの大部分を読めるようになっていると報告されている。一方で、書く力は読む力よりも遅れて育ち、鏡文字（左右が反対の文字）も5歳ごろにはよく見られ、多くは自然に消えていく。
- **アプリへの反映**：
  - アプリは「読み」を先に、「書き」をあとから進められるように、読みと書きの進み具合を別々に記録する。
  - アプリは鏡文字を「まちがい」として強く指摘せず、お手本と並べて見比べる形でやさしく気づかせる。
  - アプリはカタカナをひらがなのあとに学ぶ順番を基本にする（保護者が変更可）。

### 1-9. まちがえやすい文字は「並べて比べる」
- **研究内容**：似ている刺激を並べて違いに注目させる学習（弁別学習）は、混同を減らすとされる。かなには「さ／ち」「ぬ／め」「わ／ね／れ」「シ／ツ」「ソ／ン」など、幼児がまちがえやすい組み合わせがある。
- **アプリへの反映**：アプリは両方の文字を学んだあとに、「どっちかな？」という見比べクイズを出し、違うところ（はねる・むすぶ・向き）を色で強調する。

## 2. アプリの企画

### 2-1. コンセプト
**「みて・きいて・かいて・つかう」**
子どもは1つの文字について、書き順を「みて」、読みを「きいて」、指で「かいて」、その文字を使ったことばで「つかう」。この4つを毎回くり返すことで、子どもは文字の形・音・意味をつなげて覚える。

- 仮タイトル：**「もじもじ たんけん」**
- キャラクター：文字の島をめぐる案内役の動物（例：ペンギンの「ぺんた」）

### 2-2. 対象と利用シーン
| 項目 | 内容 |
|---|---|
| 主な利用者 | 5歳児（ひとりで操作できる設計にする） |
| 見守る人 | 保護者（設定・進み具合の確認） |
| 端末 | タブレット（主）、スマートフォン、PC（マウスでも動くが推奨はタッチ） |
| 1回の時間 | 5〜10分 |

### 2-3. 学習する内容
- **ひらがな**：清音46字 → 濁音・半濁音（が・ぱ など）→ 小さい文字（ゃ・っ など）
- **カタカナ**：同じ順番で学ぶ
- **単語**：1文字につき3〜5語、合計で約300〜400語
  - 例（「あ」）：あり、あめ、あひる、あさがお
  - 例（「ア」）：アイス、アヒル、アメリカ
  - 単語は「最初の文字」で出すものに加えて、「まんなか」「さいご」にその文字が入る単語も入れる（例：「か」→ さかな、すいか）。
  - アプリはすべての単語にイラストと音声をつける。
- **学ぶ順番**：アプリは五十音順ではなく、書きやすい形・よく使う文字から始める。
  - 例：く → し → つ → の → へ → い → こ → り …（画数が少なく、まっすぐ・単純な形から）
  - アプリは五十音順で学ぶモードも選べるようにする。

### 2-4. 画面と遊び方

#### ① ホーム（しまのちず）
- 子どもは、行ごと（あ行・か行…）の島を選ぶ。
- アプリは学んだ文字に花やシールを表示し、進み具合を見て分かるようにする。

#### ② もじの れんしゅう（1文字の学習：約2分）
1. **みる**：アプリが文字を大きく表示し、「あ」と読み上げ、書き順アニメーションを流す。
2. **なぞる**：子どもがお手本をなぞる。アプリは1画ごとに判定し、正しければ線が光る。
3. **うすく なぞる**：子どもがうすいお手本の上に書く。
4. **ひとりで かく**：子どもがお手本なしで書く。アプリは書けた文字をお手本と並べて見せる。
5. **ことば**：アプリがその文字を使った単語を、絵と音声で2〜3個紹介する（拍ごとに文字が光る）。

#### ③ ことばあつめ（単語あそび）
- 絵を見て、最初の文字を選ぶ（例：🍎の絵 →「り」を選ぶ）。
- 音を聞いて、文字カードを並べて単語をつくる（例：「い・ぬ」）。
- 拍の数だけ手をたたく（タップする）。

#### ④ おさらい クイズ（分散学習・思い出す練習）
- アプリは、以前学んだ文字の中から復習の時期が来たものを自動で選んで出題する。
- 出題形式：音を聞いて文字を選ぶ／似ている文字の見比べ／ひとりで書く。

#### ⑤ ごほうび
- 子どもは学習で「シール」を集め、ずかん（シール帳）に貼れる。
- アプリは、順位や制限時間など、競争や焦りを生む仕組みは入れない。

#### ⑥ おうちのひと ページ
- 保護者は、文字ごとの「読める／書ける」の状況を確認できる。
- 保護者は、1日の利用時間の上限、ひらがな・カタカナの順番、学ぶ順番（やさしい順／五十音順）を設定できる。
- 子どもが誤って開かないように、アプリはこのページの入口に簡単な大人向けの確認（例：「3＋4は？」）を置く。

### 2-5. 書き取りの判定方法（技術の要点）
- **書き順データ**：アプリは KanjiVG（ひらがな・カタカナを含む書き順SVGデータ、ライセンスはCC BY-SA 3.0）を使う。アプリはクレジット表記をする。
- **判定の考え方**：アプリは1画ごとに、子どもの線とお手本の線を同じ点数に間引いて比べ、
  - 始点の位置
  - 線の方向
  - 全体の形の近さ（点どうしの平均距離）

  をチェックする。5歳児向けなので、アプリは判定をかなり甘めにし、「形がだいたい合っていて、順番と方向が正しければOK」とする。
- **関連ライブラリ候補**：Hanzi Writer（漢字向けの書き順・判定ライブラリ）の考え方を参考にする。

### 2-6. 技術構成（案）
| 項目 | 内容 |
|---|---|
| 形式 | 静的なWebアプリ（サーバー不要、GitHub Pages などで公開可能） |
| 言語 | HTML / CSS / JavaScript（TypeScript） |
| 書く画面 | Canvas または SVG ＋ Pointer Events（指・ペン・マウスに対応） |
| 音声 | 録音した音声ファイルを基本とする。開発初期はブラウザの読み上げ機能（Web Speech API, ja-JP）で代用する |
| 保存 | 端末内（localStorage / IndexedDB）。個人情報は集めない |
| オフライン | PWA化して、通信がなくても使えるようにする |

※ブラウザの読み上げ機能は、端末によって声や読み方が不自然になることがあるため、本番では録音音声に置き換えることを推奨する。

### 2-7. 開発の進め方（段階）
| 段階 | 内容 |
|---|---|
| **MVP（最初の版）** | ひらがな46字の書き順アニメーション・なぞり書き・判定・読み上げ・各文字2〜3語の単語 |
| **第2版** | カタカナ46字、単語の追加（各3〜5語）、ことばあつめ、シール |
| **第3版** | おさらいクイズ（分散学習）、似ている文字の見比べ、おうちのひとページ |
| **第4版** | 濁音・半濁音・小さい文字、PWA化、録音音声への置き換え |

### 2-8. 効果の確かめ方
- アプリは文字ごとに「読めた回数」「ひとりで書けた回数」「最後に正解した日」を記録する。
- 保護者は、1か月ごとに「読める文字数」「書ける文字数」の変化をグラフで確認できる。
- 開発者は、実際に5歳児に使ってもらい、「つまずく画面」「飽きるタイミング」を観察して改善する。

## 3. 次に決めたいこと（相談事項）
1. 主に使う端末（タブレット／スマホ／PC）はどれか。
2. 音声は、ブラウザの読み上げで始めてよいか、または最初から録音（保護者の声など）を使いたいか。
3. 単語のイラストは、絵文字で始めてよいか、または専用のイラストを用意したいか。
4. 最初の版（MVP）は、ひらがなだけで始めてよいか。
